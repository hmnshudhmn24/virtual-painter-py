# Virtual Painter

A **Python AI-Powered Virtual Painter** that:

- Uses a webcam to track hand gestures  
- Allows users to draw on the screen using finger movements  
- Supports different colors and brush sizes  

## Requirements  
- Python 3.x  
- `opencv-python`, `numpy`, `mediapipe` (install using `pip install opencv-python numpy mediapipe`)  

## How to Run  
1. Open a terminal and navigate to the project directory.  
2. Run the script:  
   ```sh  
   python virtual_painter.py  
   ```  
3. Use your index finger to draw on the screen.  
4. Press 'q' to exit.
